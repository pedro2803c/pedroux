# Pedro Henrique · Web Designer Sênior

Portfólio de Pedro Henrique Coelho de Souza: web design, UX/UI e branding.

**Site:** https://designerux.vercel.app
**LinkedIn:** https://www.linkedin.com/in/pedro-henrique-coelho-de-souza-8a600a289/

## Cases

- **Abreu Oliveira**: landing page para tráfego pago (~30 contratos por mês)
- **Atlantec**: reestruturação de catálogo B2B
- **Grupo Brasil**: rebranding, site e blog
- **Hooney V2**, **WebQuarto V2** e **MoradiaMatch**: UX/UI de produtos, com MVP no Figma
- **Beeviral**: manual de marca e identidade visual

## Estrutura

Site estático em HTML, CSS e JavaScript, sem build:

| Pasta / arquivo | Conteúdo |
|---|---|
| `index.html` | Página inicial |
| `*.html` | Uma página por case |
| `assets/style.css` | Visual do site inteiro |
| `assets/main.js` | Lista de projetos, filtros, carrossel e efeitos |
| `assets/i18n.js` | Tradução para inglês (botão PT / EN) |
| `prints/` | Prints dos projetos (WebP) |
| `manual/pages/` | Páginas do manual da Beeviral (`sm/` = versão leve do carrossel) |
| `cv/` | Currículo em PDF |

Publicado na Vercel: cada envio para este repositório gera um novo deploy automaticamente.
